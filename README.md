# Customer Behavior Analytics Dashboard

## Project Overview

This project analyzes customer purchasing behavior using Python, SQL, and Power BI.

The objective is to understand customer preferences, purchasing patterns, revenue generation, subscription behavior, and product category performance.

The project follows a complete Data Analytics workflow:
- Data Collection
- Data Cleaning
- Data Analysis
- Data Visualization
- Business Insights

---

## Tools and Technologies

- Python
- SQL
- Power BI
- Excel
- Pandas
- NumPy

---

## Project Objectives

- Analyze customer purchasing trends
- Identify high-performing product categories
- Understand customer subscription patterns
- Study revenue contribution by age group
- Build interactive dashboards

---

## Key Performance Indicators (KPIs)

- Total Customers
- Average Purchase Amount
- Average Review Rating
- Revenue by Category
- Sales by Category
- Revenue by Age Group
- Sales by Age Group

---

## Dashboard Features

- Interactive Filters
- Customer Segmentation
- Revenue Analysis

- Product Category Analysis
